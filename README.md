# قارئ ONT هواوي — Huawei ONT Reader

تطبيق أندرويد يدخل على جهاز ONT هواوي عبر الواي فاي ويعرض:

- قوة الإشارة المستلمة RX Power (dBm) مع تقييم بالألوان
- البور المرسل TX Power (dBm)
- درجة حرارة الجهاز (الموديول البصري)
- استهلاك المعالج CPU والذاكرة RAM
- حالة وسرعة كل منفذ LAN: ‏GE (1000M) أو FE (100M) أو غير متصل
- الموديل والرقم التسلسلي والسوفتوير (إذا كانت متوفرة في الصفحة)

القيم الافتراضية: `192.168.100.1` / `telecomadmin` / `admintelecom` (يمكن تغييرها من الشاشة).

## بناء ملف APK مجاناً عبر GitHub (يمكن من الهاتف)

1. أنشئ حساباً في github.com ثم أنشئ مستودعاً جديداً (New repository).
2. ارفع كل محتويات هذا المجلد (فك الضغط أولاً) عبر **Add file → Upload files**.
   تأكد أن مجلد `.github/workflows` رُفع أيضاً (إن لم يظهر، أنشئ ملفاً جديداً بالمسار
   `.github/workflows/build.yml` والصق محتواه).
3. افتح تبويب **Actions**؛ سيبدأ البناء تلقائياً (حوالي 5 دقائق).
4. بعد ظهور العلامة الخضراء ✔ افتح البناء وانزل إلى **Artifacts** ونزّل `HuaweiOntReader-apk`.
5. فك الضغط وثبّت ملف `app-release.apk` (فعّل "التثبيت من مصادر غير معروفة").

أو بواسطة Android Studio: افتح المجلد ثم Build → Build APK.

## طريقة العمل

1. يحاول تسجيل الدخول مباشرة (`GetRandCount.asp` + `login.cgi` بكلمة مرور Base64).
2. إذا فشل، أو كان السوفتوير يستخدم تشفيراً حديثاً، يفتح صفحة الجهاز في WebView مخفي
   ويملأ الحقول ويضغط دخول بنفسه، ثم يأخذ جلسة الدخول.
3. يقرأ الصفحات:
   - `/html/amp/opticinfo/opticinfo.asp` (الإشارة والحرارة)
   - `/html/ssmp/deviceinfo/deviceinfo.asp` (CPU والذاكرة)
   - `/html/amp/ethinfo/ethinfo.asp` (المنافذ)
4. يستخرج القيم من كود JavaScript داخل الصفحة بربط أسماء المعاملات بالقيم، لذلك يتحمل اختلاف الترتيب بين الموديلات.
5. يسجل الخروج بعد القراءة حتى لا يحجز جلسة الإدارة.

التطبيق يربط نفسه بشبكة الواي فاي تلقائياً، فيعمل حتى لو كانت بيانات الهاتف مفعّلة والواي فاي بلا إنترنت.

## إذا لم تظهر قراءة معيّنة

اضغط **مشاركة للتشخيص** وأرسل النص الناتج، فهو يحتوي على صفحات الجهاز الخام (بدون كلمة المرور)
ويكفي لتعديل المحلل ليدعم ذلك الموديل.
